# Portfolio Admin CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make all portfolio content editable from a secured `/admin`, persisted in SQLite + an uploads folder on a Docker volume, with a switchable uploaded/generated CV and a `mailto:` contact.

**Architecture:** Framework-free server logic lives in `server/lib/*.ts` (explicit imports, unit-tested with `bun test`). Nitro routes/middleware under `server/` are thin wrappers. Content is stored as one validated JSON document per section in a SQLite `sections` table. Public pages SSR from `GET /api/content`; admin is a generic section editor driven by field descriptors.

**Tech Stack:** Nuxt 4 (Nitro `bun` preset), Bun (`bun:sqlite`, `bun test`, `Bun.password`), zod 4, h3 `useSession`, `pdf-lib`, Tailwind 4, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-23-admin-cms-design.md`

## Global Constraints

- Single admin; credentials from env `ADMIN_USERNAME`, `ADMIN_PASSWORD`; app refuses to boot if either is missing or password < 12 chars.
- Persistence: SQLite file + `uploads/` inside `DATA_DIR` (default `./.data`; Docker: `/data` volume).
- Session cookie: sealed, httpOnly, SameSite=Strict, Secure in production unless `COOKIE_SECURE=false`. Secret from `SESSION_SECRET` (≥32 chars) else random per boot.
- All admin writes require header `x-csrf-token` matching the session's token.
- Uploads: images (png, jpeg, webp, avif, gif) ≤ 5 MB, PDF ≤ 10 MB; type decided by magic bytes, never by filename/MIME; random filenames; SVG uploads rejected.
- Resend, `/api/contact`, and the contact form are removed; contact is `mailto:` only. FAQ stays on `/contact`.
- Existing look and Tailwind classes are preserved; no GitHub Actions.
- Commits carry no AI attribution trailer (user's global rule).

## Review Focus

- Wrong username vs wrong password: identical 401 body and no early-return timing difference.
- Upload named `x.png` containing HTML/SVG/EXE bytes, an oversize file, and `/uploads/..%2f..%2fetc/passwd` traversal: all rejected, nothing written outside `uploads/`.
- `PUT` section without/with wrong CSRF token → 403; invalid payload → 400 and stored data unchanged.
- Generated CV with empty sections, very long text, and non-Latin/emoji characters builds a valid PDF (no encoding crash).
- `cvMode='uploaded'` but no file uploaded → `/cv` falls back to the generated PDF; editing content invalidates the cached generated PDF.
- Boot with missing/weak admin env fails fast with a clear message.

### Task 4: Session endpoints, guards, headers, startup validation

**Files:** Create `server/plugins/startup.ts`, `server/utils/store.ts` (singleton `useStore()`), `server/utils/session.ts` (`getAdminSession(event)`, `requireAdmin(event)`, `requireCsrf(event)`), `server/middleware/guard.ts`, `server/middleware/security-headers.ts`, `server/api/auth/login.post.ts`, `server/api/auth/logout.post.ts`, `server/api/auth/session.get.ts`

**Interfaces:**
- Consumes: Task 2/3 exports.
- Produces: `POST /api/auth/login {username,password}` → `200 {csrfToken}` + cookie, or generic `401 {message:'Invalid credentials'}`, or `429` with `Retry-After`; `GET /api/auth/session` → `{authenticated:boolean, csrfToken?:string}`; `POST /api/auth/logout` (requires CSRF) clears session. `guard.ts` returns 401 for any `/api/admin/**` without a session and 403 for non-GET/HEAD `/api/admin/**` without a matching `x-csrf-token`. `requireAdmin`/`requireCsrf` helpers for routes. Headers on all responses: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`, a CSP (self + GA hosts + inline styles/scripts needed by Nuxt), `X-Robots-Tag: noindex` on `/admin*` and `/api/*`. Login rate limit keyed by client IP (`TRUST_PROXY=true` enables `x-forwarded-for`): 5 failures / 15 min → 15 min lock; login regenerates the session.

### Task 5: Uploads (lib, admin endpoint, public serving)

**Interfaces:**
